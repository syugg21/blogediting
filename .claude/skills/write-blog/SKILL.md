# 블로그 자동 작성 파이프라인

`/write-blog [선택: 원하는 주제나 분야]` 형태로 호출된다. 인자가 있으면 1단계에서
그 주제/분야로 검색 범위를 좁히고, 없으면 CLAUDE.md에 정의된 카테고리를 폭넓게
탐색한다.

먼저 CLAUDE.md를 읽어 블로그 성격/산출물 규칙을 확인한다.

## 파이프라인 실행 순서

Agent 도구로 아래 3개 subagent를 **순서대로, 각 단계 결과를 다음 단계 프롬프트에
그대로 포함해서** 호출한다. subagent는 이전 대화를 보지 못하므로 필요한 맥락(이전
단계의 전체 출력)을 프롬프트에 명시적으로 담아야 한다.

### 1단계 — 주제 선정 (`trend-researcher`)

- `subagent_type: trend-researcher`
- 사용자가 지정한 주제/분야가 있으면 프롬프트에 포함해 그 범위 내에서 탐색하도록
  지시. 없으면 폭넓게 탐색하도록 지시.
- 결과: 선정 주제 + 핵심 사실 + 출처 + 시의성 주의사항이 담긴 리서치 보고서.

주제가 선정되면 사용자에게 한 줄로 어떤 주제가 선정됐는지 알린다 (승인을 기다리지
않고 바로 다음 단계로 진행).

### 2단계 — 제목 및 본문 작성 (`blog-writer`)

- `subagent_type: blog-writer`
- 프롬프트에 1단계의 리서치 보고서 전체를 그대로 첨부.
- 결과: 제목 후보 + 본문 초안 + 출처 + 편집자에게 전달 사항.

### 3단계 — 편집 및 저장 (`blog-editor`)

- `subagent_type: blog-editor`
- 프롬프트에 2단계의 초안 전체(제목 후보, 본문, 편집자 전달 사항)를 그대로 첨부.
- 결과: `posts/YYYY-MM-DD-slug.md`에 저장 완료, 저장 경로와 수정 요약 반환.

## 최종 보고

3단계가 끝나면 사용자에게 다음을 보고한다.

- 저장된 파일 경로
- 최종 제목
- 선정된 주제와 선정 이유 (1~2문장 요약)
- 주요 출처 링크
